# Operating-Plattforms
The client, The Gaming Room, wanted to take their Android game Draw It or Lose It and expand it so people could play on pretty much any device. Instead of keeping it as a mobile-only app, they needed a web-based game that works on desktops (Linux, macOS, Windows) and mobile devices (iOS and Android). The goal was to make it scalable so thousands of players could use it at once, while still keeping the gameplay smooth and responsive. I think I did a good job breaking down the different platforms and explaining why a Linux-based server and a browser-based client made the most sense. Working through the design document really helped me think about the bigger picture before coding—like how everything connects, how it scales and what the user experience will be like.

If I had to improve something, I’d probably go back and add more detail to areas like memory and storage management, maybe with clearer examples or visuals. When designing the system, I focused on what the user actually needs: fast performance, easy access on any device and no complicated setup, and built the design around that. That’s important because even a technically strong system won’t work if it’s frustrating for users. Overall, I approached the design by starting big and then breaking it into smaller parts (server, client, database). In the future, I’d keep using that approach but also spend more time on early testing and maybe simple prototypes to catch issues sooner.
